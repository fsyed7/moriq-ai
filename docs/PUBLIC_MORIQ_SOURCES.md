## Agreed starting point

Legitimate public MORIQ sources are part of the initial knowledge scope alongside curated architectural knowledge. Private/internal data is reserved for a later approved phase. This review specifies source categories, not particular URLs; no specific source is approved or ingested by this document.

Verify that a source actually represents the intended MORIQ organization or project before using it. Record publisher identity, provenance, usage rights, date/version, and the claims it can support. Do not infer internal policies, confidential project details, or working practices from public material or similarly named organizations.
