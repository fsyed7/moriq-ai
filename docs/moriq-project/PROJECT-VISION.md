# MORIQ AI project vision
MORIQ AI — Architectural Intelligence & Knowledge Assistant is a specialized architecture knowledge platform built on an Open WebUI foundation. Its intended users are architects, designers and junior staff who need to distinguish approved project information, architectural explanation and recommendations.

The intended differentiation is evidence discipline plus a purpose-built dark architectural studio interface: one assistant supports MORIQ knowledge, architectural reasoning and adaptive Guide/Freshie teaching. A familiar practice must never be presented as a verified MORIQ policy. A citation is a traceable reference, not proof of the claim attached to it.

V1 aims to connect Studio, Brain, approved retrieval and backend request lifecycle with review boundaries, bounded errors, testing and reproducible setup. The recovered state is a collection of working offline components and a fixture UI, not that completed integrated product. Live inference is a separately authorized future gate.

Post-V1 ideas include project workspaces, architectural document intelligence, drawing/PDF interpretation, CAD/BIM integrations, collaboration and standalone applications. They are product concepts, not delivered capabilities. No deadline is promised by this migration.
